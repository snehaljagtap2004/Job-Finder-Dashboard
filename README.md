# Job Finder Dashboard 💼

A modern and responsive **Job Finder Dashboard** built using HTML, CSS, and JavaScript. The project provides a simple interface for searching jobs, viewing recommended jobs, saving jobs, tracking applications, and managing a user profile.

## 🚀 Features

* 📊 Dashboard with recommended jobs
* 🔍 Job search section
* 💼 Job listings
* 🔖 Saved jobs
* 📋 Application tracking
* 👤 User profile section
* 📱 Responsive design
* 🧭 Single-page navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/jha552093-cyber/job-finder-dashboard.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or use **Live Server** in Visual Studio Code.
